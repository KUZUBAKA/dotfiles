## 並び方のルール

Karukan は「学習 → ユーザー辞書 → AI → システム辞書」の順に候補を並べます。

- `user_dicts/` には、システム辞書が知らない読みの言葉だけを入れています。
  その読みを打つのはその言葉を出したいときなので、1番目に出ても困りません。
- 普通の言葉と読みが同じ名前（ゆうじ → 悠仁、まい → 丁礼田舞 など）は `system/top.tsv` です。
  AI の候補のすぐ後ろに出るので、「ゆうじ」で「有事」を出したいときの邪魔をしません。
- 人の名前は「フルネーム」「姓」「名」「姓 → フルネーム」「名 → フルネーム」で登録しています。
  たとえば「ごじょう」でも「さとる」でも「五条悟」が候補に出ます。

## 単語の使われやすさ（freq.tsv.xz）

`system/freq.tsv.xz` は「読み・表記・コスト」の表です。コストは Mozc（Google 日本語入力のオープンソース版）の辞書が持っている数字で、小さいほどよく使う言葉です。
`setup.sh` がこの数字をシステム辞書の点数（score）として書きこみ、Karukan（パッチ第8版）が次のことに使います。

- 1語だけを変換するとき、AI の点数にこの数字を足して並べる（ぼく → 僕 が 朴 より先、わたし → 私）
- AI がひらがなのままにした言葉に、かなと同じくらいよく使う漢字の書き方があれば、漢字を先にする（いろんな単語 → 色んな単語）
- AI がほとんど同じ点数をつけた同じ読みの言葉は、ずっとよく使うほうを先にする（返還制度が悪い → 変換精度が悪い）

`〈仮名〉から` のように `〈仮名〉` で始まる行は、「このかなは助詞・助動詞などで、かなのまま書くのが普通」という印です（から、ます、こと など 2,140 語）。
この印がある読みは、同じ読みの漢字（殻、増す、事）がどれだけよく使われていても、勝手に漢字にはなりません。

## 数字の後ろの助数詞

`user_dicts/03-counters.txt` の読みは `〈数〉さい` のように `〈数〉` で始まります。「数字のすぐ後ろで」という印で、キーボードからは打てません。
18 の後ろで さい を変換すると、学習した「再」や AI の「才」より先に「歳」が出ます。表記が2つ以上ある読み（かい → 回、階）は AI が文脈で選びます。
自分の好みに変えたいときは、この書類の行を書きかえるか、変換で選び直してください（数字の後ろで選んだ変換は、数字の後ろ用として別に学習されます）。

## ＠キャラクター

＠ に続けてキャラクターの名前の読みを打って Space を押すと、そのキャラクターの言葉がまとめて出ます。
キーボードの @ を押すと、読みでは ＠（全角）になります。

- ＠こいし → 古明地こいし、古明地、二つ名、能力、技、スペルカード（表象「夢枕にご先祖総立ち」…）
- ＠しろこ → 砂狼シロコ、砂狼、シロコ、衣装違い、EX・ノーマル・パッシブ・サブスキル、固有武器
- ＠めぐみ → 伏黒恵、伏黒、恵、十種影法術、玉犬、白、黒、渾、鵺、大蛇、蝦蟇、不知井底、満象、脱兎、円鹿、貫牛、虎葬、八握剣異戒神将魔虚羅、嵌合暗翳庭
- ＠たんじろう → 竈門炭治郎、水の呼吸 壱ノ型 水面斬り …、ヒノカミ神楽 壱ノ型 円舞 …
- ＠るふぃ → モンキー・D・ルフィ、ゴムゴムの銃 …

名前の読み（＠こいし）でもフルネームの読み（＠こめいじこいし）でも出ます。技や組織の読み（＠みずのこきゅう）でも、その下の言葉が出ます。

東方・ブルーアーカイブ・呪術廻戦に加えて、Wikipedia 日本語版に記事や登場人物の一覧がある180作品を入れています
（ONE PIECE、NARUTO、BLEACH、HUNTER×HUNTER、ドラゴンボール、鬼滅の刃、僕のヒーローアカデミア、ジョジョ、進撃の巨人、名探偵コナン、銀魂、Fate、とある、原神、崩壊：スターレイル、ゼンレスゾーンゼロ、など）。
一覧に「名前（よみ）」の形で書かれている言葉と、文章や表の中に「螺旋丸（らせんがん）」「"伸縮自在の愛（バンジーガム）"」やルビ（鍾離にショウリ）の形で書かれている言葉を、機械的に取り出しています。次のことを知っておいてください。

- ＠ で技が出るのは、Wikipedia でその人物の下に技が並んでいる作品だけです。NARUTO の術や HUNTER×HUNTER の念能力は人物の下に並んでいないので ＠ では出ませんが、読みを打てば出ます（らせんがん → 螺旋丸、かげぶんしんのじゅつ → 影分身の術、ばんじーがむ → 伸縮自在の愛）。
- Wikipedia に読みが書かれていない有名な技（影分身の術、須佐能乎、神羅天征、ジャジャン拳、百式観音 など20語）は、表記が記事にあることを確かめたうえで、作中の読みで入れています。
- 漢字の名前をカタカナで呼ぶ技（当て字）は、その読みをシステム辞書が知らないときだけ入れています（めもり → 容量 のように、普通の言葉の邪魔になるものは入れていません）。
- 原神・崩壊：スターレイル・ゼンレスゾーンゼロは、記事の表にルビつきで書かれているキャラクターの名前です（ふーたお → 胡桃、らいでんしょうぐん → 雷電将軍）。技は入っていません。
- 技のほかに、その人物の項目に書かれている関係者や形態の名前が混ざることがあります。
- 鬼滅の刃の呼吸の型は Wikipedia に無いので、ciatr の一覧から入れています。使い手は「呼吸ごと」です（＠ぜんいつ に雷の呼吸の全部の型が出ます）。

## 使い方

```bash
bash setup.sh             # これだけで全部そろいます
bash setup.sh --update    # Karukan も最新版（パッチ入り）に入れ直す
bash setup.sh --refresh   # 公式のシステム辞書をダウンロードし直す
```

`setup.sh` は次のことを順番にやります。

1. パッチ入りの Karukan（karukan-kz-git）が無ければ `karukan-kz-install.sh` で入れる
2. 公式のシステム辞書をダウンロードし、`system/` の言葉を足して `dict.bin` を作る
   （材料が変わっていなければ作り直さないので、2回目からは数秒で終わります）
3. `~/.local/share/karukan-im/` に `dict.bin` と `user_dicts/*.txt` を登録する
   （あなたの `~/dotfiles/KDE-IME.txt` は `00-KDE-IME.txt` という名前でつなぎます）
4. 登録した辞書が読めるか確かめて、Fcitx5 を再起動する

ユーザー辞書は Mozc と同じ txt のまま登録するので、そのまま書き換えられます。
書き換えたら `bash setup.sh` をもう一度実行するか、Fcitx5 を再起動してください。
`dict.bin` は公式より大きいので、**パッチ入りの Karukan でしか読み込めません**。
